  **Use when:** the user types `/a11y [target]` to audit accessibility of a
  UISpec, URL, or built artifact against WCAG 2.2.
  **Do NOT use when:** the user wants architectural review of a design (use
  `architecture.review-design`), code review (`engineering.review-diff`), or
  test coverage (`review-test-coverage`).
  **Inputs:** target identifier.
  **Outputs:** ReviewVerdict + ReviewComment under
  .agents/state/findings/a11y/<id>/quality/.
argument-hint: "<target>"
allowed-tools: [Task, Read, Bash, Write]
---

# /a11y

Dispatch `a11y-reviewer` against the named target.
